# Working on this repo

- Work directly on `main`. Commit and push to `main` (`git push origin main`); don't use separate feature branches. GitHub Pages serves `main`: https://salvationbacon.github.io/Monster-Hunter/
- After each push, give the play links: the Pages site and the GitHub repo.
- The game is the single file `index.html`. Run `node tools/check.js` before pushing; all checks must pass.
- Design decisions are logged in `concepts/DECISIONS.md`; agreed ideas not yet built go in `concepts/TODO.md`.
